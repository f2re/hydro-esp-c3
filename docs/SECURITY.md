# Безопасность HydroESP-C3

HydroESP-C3 рассчитан на **доверенную домашнюю/лабораторную LAN**. Цель проекта — простая эксплуатация контроллера, а не сложная система пользователей и паролей.

## Setup-сеть

При первой настройке устройство создаёт:

```text
SSID: HydroESP-Setup
Пароль: нет
URL: http://192.168.4.1
```

Сеть намеренно открытая, чтобы установка не требовала поиска ключей, логинов и дополнительных шагов. После сохранения домашнего Wi‑Fi устройство перезагружается и работает в вашей LAN.

Не оставляйте контроллер доступным из интернета и не делайте port-forward на его HTTP-порт.

## Что остаётся полезным

- пароль домашнего Wi‑Fi не возвращается через API и не входит в backup;
- изменение состояния выполняется через POST;
- API проверяет расписание и конфигурацию;
- запуск насоса всегда ограничен максимальным временем;
- reboot/OTA выключают насос;
- режим обслуживания останавливает плановую автоматику;
- restore оставляет автоматику на паузе до проверки;
- калибровка разрешена только при paused automation и выключенном насосе.

Это эксплуатационные предохранители, а не «система авторизации».

## Чего нет специально

В базовом варианте нет:

- логина в Web UI;
- device key для setup Wi‑Fi;
- ролей пользователей;
- HTTPS-сертификатов;
- обязательного облака.

Если контроллер используется в недоверенной сети, изоляцию проще и надёжнее сделать на уровне самой сети/VLAN.

## Что действительно важно дальше

Для полива полезнее аппаратная безопасность:

1. датчик минимального уровня;
2. подтверждение фактического потока;
3. нормальное питание и штатная brown-out protection.

Именно эти механизмы защищают насос и растения при реальном отказе гидравлики.
