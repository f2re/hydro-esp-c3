# Wi‑Fi при установке

`install.sh` / `install.ps1` сначала используют `WIFI_SSID` / `WIFI_PASSWORD` из окружения или локального `.env`.

Если данных нет, установщик один раз спрашивает SSID и пароль, сохраняет их в локальный `.env` и использует автоматически при следующих установках. `.env` исключён из Git; на Linux/macOS для файла выставляются права `0600`.

Если SSID оставить пустым, контроллер использует `HydroESP-Setup`.
