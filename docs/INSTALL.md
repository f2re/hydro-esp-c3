# Установка HydroESP-C3

Это руководство рассчитано на чистую **ESP32-C3 Super Mini** и установку по USB. После первой прошивки дальнейшие обновления можно выполнять из веб-интерфейса или через `hydroctl` по Wi‑Fi.

## Что понадобится

- ESP32-C3 Super Mini;
- USB-кабель **с линиями данных**, а не только для зарядки;
- Python 3.9+;
- Git;
- насос/реле и питание, подключённые по схеме проекта;
- компьютер с Windows, macOS или Linux.

PlatformIO заранее устанавливать не требуется: `tools/hydroctl.py` при необходимости создаёт локальное `.venv` и устанавливает туда PlatformIO.

## 1. Получить проект

```bash
git clone https://github.com/f2re/hydro-esp-c3.git
cd hydro-esp-c3
```

## 2. Прошить контроллер

### macOS / Linux

```bash
bash install.sh
```

### Windows PowerShell

```powershell
.\install.ps1
```

### Универсальный вариант

```bash
python3 tools/hydroctl.py install
```

Скрипт:

1. проверит PlatformIO;
2. при необходимости создаст `.venv`;
3. соберёт прошивку;
4. автоматически определит последовательный порт;
5. прошьёт ESP32-C3.

Если подключено несколько плат, укажите порт явно:

```bash
python3 tools/hydroctl.py install --port /dev/ttyACM0
```

В Windows пример порта:

```powershell
py tools\hydroctl.py install --port COM5
```

## 3. Первая настройка без зашитого пароля

Обычная сборка намеренно **не содержит пароль домашнего Wi‑Fi**.

После первого запуска:

1. подключитесь телефоном или ноутбуком к сети `HydroESP-Setup`;
2. откройте `http://192.168.4.1`;
3. в разделе **Система** задайте домашний Wi‑Fi и часовой пояс;
4. нажмите **Сохранить и перезагрузить**;
5. после подключения к домашней сети откройте `http://hydro.local`.

Если `hydro.local` не разрешается в вашей сети, используйте IP-адрес устройства, который виден в роутере, OLED или Serial monitor.

## Фабричные Wi‑Fi параметры — только при необходимости

Для стендовой партии устройств можно встроить начальные параметры сети:

```bash
python3 tools/hydroctl.py install --factory-wifi
```

Скрипт запросит SSID и пароль интерактивно; пароль не требуется передавать в командной строке.

Можно также задать заводской UTC offset:

```bash
python3 tools/hydroctl.py install --timezone 3
```

Для CI/автоматизированной сборки поддерживаются переменные окружения из `.env.example`, но файл `.env` автоматически не читается и не должен попадать в Git.

## Проверка после установки

```bash
python3 tools/hydroctl.py doctor
```

Команда проверяет:

- Python;
- PlatformIO;
- доступные serial-порты;
- доступность `hydro.local`;
- версию и build SHA прошивки;
- синхронизацию времени.

Посмотреть полный статус:

```bash
python3 tools/hydroctl.py status
```

Serial monitor:

```bash
python3 tools/hydroctl.py monitor
```

## Если порт не определяется

### Общие действия

1. замените USB-кабель;
2. подключите устройство напрямую, без пассивного USB-хаба;
3. попробуйте другой USB-порт;
4. выполните `python3 tools/hydroctl.py doctor`;
5. при необходимости удерживайте **BOOT**, нажмите/подайте **RESET**, затем повторите прошивку.

### Linux

Проверьте права на serial-порт. В большинстве дистрибутивов пользователь должен входить в группу `dialout` или эквивалентную:

```bash
sudo usermod -aG dialout "$USER"
```

После изменения группы нужно повторно войти в систему.

### macOS

Порты обычно имеют вид `/dev/cu.usbmodem*`. Проект больше не фиксирует такой путь в `platformio.ini`; порт выбирается автоматически.

### Windows

Порт отображается как `COMx`. Посмотреть найденные устройства можно через:

```powershell
py tools\hydroctl.py doctor
```

## Проверка насоса перед автономной работой

До включения автоматического графика:

1. отсоедините растения/критичный контур либо используйте тестовую ёмкость;
2. измерьте фактический расход насоса в л/мин;
3. проверьте направление реле и состояние «насос выключен» после загрузки;
4. выполните короткий ручной цикл 30 секунд;
5. убедитесь, что контроллер не перезагружается при старте насоса;
6. в разделе **Расчёт** введите измеренный расход;
7. создайте и вручную проверьте черновик расписания;
8. только затем сохраните график.

> Если ESP32 перезагружается при пуске насоса, это аппаратная проблема питания/развязки. Не маскируйте её увеличением длительности или изменением расписания. См. [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
